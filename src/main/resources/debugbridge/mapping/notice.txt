Forge 1.20.1 member mapping used by DebugBridge

forge_1_20_1.tsv.gz is a transformed join of Mojang member names and MCPConfig
SRG names. It contains renamed members only, grouped by owner with method
parameter signatures. It is not an original or unmodified upstream mapping.
Source SHA-256 values are embedded in the decompressed resource header.
Regenerate with tools/generate_forge_mapping.py --mojang <client mappings>
--srg <MCPConfig mappings.txt> [--runtime-jar <client-srg.jar>].

Sources:
- Minecraft Java 1.20.1 official client ProGuard mappings, supplied by Mojang's
  version manifest. Source filename: client-1.20.1-20230612.114412-mappings.txt.
- MCPConfig 1.20.1-20230612.114412, config/joined.tsrg:
  https://maven.minecraftforge.net/de/oceanlabs/mcp/mcp_config/1.20.1-20230612.114412/mcp_config-1.20.1-20230612.114412.zip
  https://github.com/MinecraftForge/MCPConfig
